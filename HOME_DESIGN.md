### **HOMEPAGE**

Design a modern, futuristic dark-mode cybersecurity web landing page for an application named “CloudGuard EMT” (Enhanced Merkle Tree).



**🎨 Theme \& Visual Style**

* Style: Cybersecurity, futuristic, minimal, clean UI
* Inspiration: Combination of Matrix aesthetic + Vercel UI + modern SaaS dashboard
* Mood: Secure, high-tech, premium, trustworthy
* Avoid clutter, focus on clarity and hierarchy



**🎨 COLOR SYSTEM (STRICT)**

Use the following color palette:

* Background: #0B1120 (very dark blue)
* Surface/Card: #1E293B
* Border: #334155
* Primary (main action / branding): #10B981 (neon emerald)
* Secondary (accent/glow): #06B6D4 (cyan)
* Danger: #EF4444 (red)
* Warning: #F59E0B (amber)
* Heading text: #F8FAFC
* Body text: #94A3B8



**✍️ TYPOGRAPHY**

* Headings: Space Grotesk, bold, futuristic feel
* Body: Inter, clean and readable
* Monospace (for code preview): JetBrains Mono
